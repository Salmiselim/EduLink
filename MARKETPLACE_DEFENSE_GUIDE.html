1 Architecture Overview: How All 14 Files Connect Together

Your Marketplace uses a clean MVC / Observer Architecture divided into 5 folders inside lib/features/marketplace/:

🧱 Data Blueprint

2. Controller (1 File)

🧠 State & Rules

2 Core Layer Explained: Models, Controller & Routes (3 Files)

📄 File 1: Domain Models & Enums

lib/features/marketplace/models/marketplace_models.dart
💬 What to tell the teacher when opening this file: "This file contains all our immutable data models and enums. Every class has a copyWith() method to update state safely and toMap() / fromMap() methods to serialize objects to and from Firebase Cloud Firestore."

Enums (OfferType, OfferStatus, OrderStatus, SellerRole)

Each enum has a Dart extension attached to it that returns its French label (e.g. 'Cours particulier (1 h)'), its Material IconData, and its theme Color so UI screens don't hardcode colors or strings.

class OfferLocation

Stores the pickup point for an offer: address (street), city, lat (latitude), and lng (longitude) returned by OpenStreetMap.

class Offer

Represents an announcement in the catalog: id, title, description, type, subject, price, sellerId, sellerRole, status, viewsCount, salesCount, ratingAvg, reportsCount, and location.

class AvailabilitySlot

Represents a 1-hour tutoring slot: id, offerId, date (e.g. 'Mar 10 Nov 2026'), startTime, endTime, isBooked (boolean lock), and orderId. Includes clearOrderId: true in copyWith() to unlock a slot when an order is rejected.

class MarketplaceOrder

Represents a transaction between buyer and seller: stores offerId, buyerId, sellerId, amount, slotId, slotLabel, meetingLink (Jitsi URL), status, and unreadCount.

class OfferReview & ChatMessage

OfferReview stores 1-to-5 star verified ratings after an order is completed. ChatMessage stores messages (and system notifications) inside an order's chat room.

🧠 File 2: Central State Controller (The Brain)

lib/features/marketplace/data/marketplace_mock_data.dart
💬 What to tell the teacher when opening this file: "This is our central controller using Flutter's ChangeNotifier (Observer pattern) and the Singleton pattern (MarketplaceController.instance). It enforces all business rules—like locking slots, auto-hiding reported offers at 3 reports, and generating Jitsi links—and syncs in real time with Cloud Firestore."

connectFirestore()

Subscribes to 4 real-time Firestore streams (watchOffers, watchSlots, watchOrders, watchReviews). If the cloud collection is empty on first run, it seeds the initial catalog automatically.

createOffer(...) & updateOffer(...)

Creates or updates an Offer + its list of 1-hour AvailabilitySlot objects, persists them to Firestore, and calls notifyListeners() so the catalog refreshes immediately.

reportOffer(offerId, reason, details)

Increments reportsCount on the offer and writes a document to the Firestore reports collection. Rule: If reportsCount >= 3, status becomes OfferStatus.hidden automatically.

createOrder(...)

Creates a new MarketplaceOrder. If the offer is a private lesson with a chosen slotId, it immediately sets slot.isBooked = true so no other student can double-book that hour.

updateOrderStatus(orderId, newStatus)

Handles the order lifecycle:
• If accepted on a lesson → generates https://meet.jit.si/edulink-$orderId.
• If rejected or cancelled → frees the slot (isBooked: false).
• If completed → increments salesCount and awards seller badges.

submitReview(order, rating, comment)

Saves an OfferReview, marks order.hasReview = true, and recalculates the offer's weighted average rating (ratingAvg) and ratingCount.

3 Services Layer Explained: External APIs & Cloud Firestore (3 Files)

These 3 files handle all external HTTP requests, deep links, and database operations:

📅 File 4: Calendar API Service (Today Rule + Holidays API + Google Calendar)

lib/features/marketplace/services/calendar_api_service.dart
💬 What to tell the teacher when opening this file: "This service does 3 things: (1) it enforces that all availability dates start from today (DateTime.now()) and parses/formats French dates, (2) it calls the Nager.Date REST API to check if a selected date is an official Tunisian public holiday or weekend, and (3) it builds Google Calendar event deep links."

todayNormalized() & formatRelativeDay(days)

todayNormalized() strips hours/minutes from DateTime.now() to get midnight today. formatRelativeDay(0) formats today in French (e.g. 'Mar 10 Nov 2026'), formatRelativeDay(1) formats tomorrow, etc.

parseSlotDate(raw) & isPastDateString(raw)

Parses a French date string back into a Dart DateTime object and checks parsed.isBefore(todayNormalized()) to reject any past date in forms.

inspectDate(DateTime date)

Calls GET https://date.nager.at/api/v3/PublicHolidays/{year}/TN using the http package (with in-memory cache _holidaysCacheByYear and offline fallback). Returns a CalendarDayInfo telling the UI if the day is a holiday, weekend, or recommended academic day.

buildGoogleCalendarUri(...) & openGoogleCalendarSlot(...)

Converts the slot date + start/end time into Google Calendar UTC format (YYYYMMDDTHHMMSSZ/YYYYMMDDTHHMMSSZ) and launches https://calendar.google.com/calendar/render?action=TEMPLATE&... via url_launcher.

// Key snippet from calendar_api_service.dart:
static DateTime todayNormalized() {
  final now = DateTime.now();
  return DateTime(now.year, now.month, now.day); // Blocks anything before today!
}

// Querying Nager.Date Public Holidays API for Tunisia (TN):
final uri = Uri.parse('https://date.nager.at/api/v3/PublicHolidays/$year/TN');
final response = await http.get(uri).timeout(const Duration(seconds: 4));

🗺️ File 5: OpenStreetMap Nominatim Geocoding Service

lib/features/marketplace/services/nominatim_service.dart
💬 What to tell the teacher when opening this file: "This service connects our app to the OpenStreetMap Nominatim REST API. It supports both forward geocoding (searching an address by text) and reverse geocoding (converting tapped map coordinates into a street address and city), plus an offline fallback list of Tunisian universities."

class NominatimPlace

Holds a geocoded location: displayName (street + neighborhood), city, lat (double), and lng (double).

searchTunisPlaces(String query)

Calls GET https://nominatim.openstreetmap.org/search?format=jsonv2&countrycodes=tn&addressdetails=1&limit=6&q=.... Parses the JSON array into List<NominatimPlace>. If offline, filters _fallbackPlaces (ESPRIT, INSAT, FST, ENIT, IHEC, ISAMM...).

reverseGeocode(double lat, double lng)

Called when the user taps directly on the map! Sends GET https://nominatim.openstreetmap.org/reverse?format=jsonv2&lat=$lat&lon=$lng&addressdetails=1 and extracts the road/suburb/building name and city so the text input updates automatically.

🔥 File 6: Firebase Cloud Firestore Service

lib/features/marketplace/services/marketplace_firestore_service.dart
💬 What to tell the teacher when opening this file: "This service encapsulates all Cloud Firestore reads, writes, batch operations, and real-time snapshots() streams across our 6 collections: offers, availabilities, orders, reviews, reports, and conversations/{orderId}/messages."

watchOffers(), watchSlots(), watchOrders(), watchReviews()

Real-time Firestore Stream methods that listen to collection changes via .snapshots() and map each document into our Dart model using fromMap().

saveOffer(), saveSlot(), deleteSlot(), replaceSlotsForOffer()

Writes or updates offers and availability slots in Firestore using .set(map, SetOptions(merge: true)) and Firestore WriteBatch for atomic multi-slot updates.

saveOrder(), saveReview(), saveReport(), sendChatMessage()

Persists orders, verified reviews, moderation reports (in the reports collection), and chat messages (inside conversations/{orderId}/messages).

7 Teacher Q&A Cheat Sheet (Exact Answers to Give)
❓ Q1: "How did you make sure nobody can pick a past date like October 30?"
Your Answer: "In calendar_api_service.dart, todayNormalized() returns DateTime.now() at midnight. We pass it as firstDate to Flutter's CalendarDatePicker in calendar_slot_picker_dialog.dart, which disables all dates before today. We also validate dates with isPastDateString() and generate all default slots relative to today with formatRelativeDay()."
❓ Q2: "What Calendar API did you use and where is it in the code?"
Your Answer: "In lib/features/marketplace/services/calendar_api_service.dart, we integrated two APIs:
1. Nager.Date Public Holidays REST API (GET https://date.nager.at/api/v3/PublicHolidays/{year}/TN) inside inspectDate() to detect Tunisian public holidays and weekends.
2. Google Calendar Template API inside openGoogleCalendarSlot() to export booked 1-hour slots (with the Jitsi Meet link or pickup address) directly into Google Calendar."
❓ Q3: "How does clicking on the map update the address text box?"
Your Answer: "In osm_map_picker_sheet.dart, the FlutterMap widget has an onTap callback (_onMapTap). When tapped, it moves the red pin to the tapped LatLng and calls NominatimService.reverseGeocode(lat, lng) (GET https://nominatim.openstreetmap.org/reverse). When the JSON response arrives, it updates the search controller text and populates _addressController.text in offer_wizard_screen.dart."
❓ Q4: "How do all the screens stay synchronized when an offer or order changes?"
Your Answer: "MarketplaceController in marketplace_mock_data.dart extends Flutter's ChangeNotifier and is shared as a singleton (MarketplaceController.instance). All 5 screens wrap their UI in a ListenableBuilder listening to that controller, and the controller also listens to real-time Cloud Firestore streams via MarketplaceFirestoreService."
